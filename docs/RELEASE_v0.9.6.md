# Keldin IPTV v0.9.6 — Global Settings navigation and TV layout

- Settings icon next to Search in the top toolbar on every main screen.
- Settings entry in the in-player options dialog. Reopens the existing app settings without a duplicate player session.
- More compact dark UI across Home, Live TV, Movies, Series, Search, Settings, posters and playback controls, preserving D-pad focus.
- Updated default-English, Bosnian, Slovenian and German interface strings in screens and player dialogs; existing general localization for additional languages remains and not every supplemental label is translated in all 16 languages.
- Preserves v0.9.5 EX-YU Filmski live category fix, EPG card layout and playback diagnostics.
- Same stable package `com.keldin.iptv` and permanent signing certificate; in-place update preserves playlists, favorites and settings. Never uninstall the old version to update.

Automated regression tests and Android release build passed before publishing. Real Xiaomi TV Box playback stutter and full language coverage still require device verification.
