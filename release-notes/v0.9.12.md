# KELDIN IPTV v0.9.12 — Faster library loading

- Adds a versioned local binary snapshot for previously imported channels. When the original JSONL catalogue is unchanged, the app can open the faster snapshot on subsequent cold launches.
- Creates the snapshot in the background after the first full load, so conversion does not hold the splash screen.
- Retains catalog-v6.jsonl as an automatic fallback; neither IPTV lists nor credentials are discarded.
- Reuses repeated category and provider strings to reduce memory usage.
- Finds the last viewed channel in one catalogue pass, off the main Android TV interface thread.
- Avoids copying the entire catalogue merely to check whether any active list has channels.
- Preserves activated/disabled provider lists, source grouping, EX YU | Filmovi & Serije, TV Grid, favorites and existing configuration.

Note: the first launch after this update can still read the old text catalogue. Faster loading is expected on the *next* complete restart, once the snapshot has finished. On devices with insufficient free storage, the snapshot is deliberately skipped.
